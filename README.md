# Snapchat EasyLens Automation Pipeline

Reverse-engineered from EasyLens HAR (`easylens.snapchat.com.har`) and frontend Next.js Webpack chunks.

## 1. System Architecture & Endpoints

EasyLens (`LensStudioWeb/2.56.0`) interacts with Snap's AI Lens Creation (AILC) backend at `https://gcp.api.snapchat.com`:

| Step | Method | Endpoint | Description |
|---|---|---|---|
| **Auth Verification** | `GET` | `/lens-studio-web-snapml/api/me` | Validates session & user identity |
| **New Conversation** | `POST` | `/lens-studio-web-ailc/assistant/new_conversation_v2` | Initializes AI assistant session |
| **Send Prompt** | `POST` | `/lens-studio-web-ailc/assistant/v1/conversations/{id}/perform_action` | Dispatches `SendPrompt` action |
| **Poll / Stream** | `GET` | `/lens-studio-web-ailc/assistant/get_lens?conversation_id={id}` | Fetches generated bundle, controller code & previews |
| **Publish** | `POST` | `/lens-studio-web-ailc/assistant/publish` | Submits lens to Snapchat public catalog |
| **Status / Snapcode** | `GET` | `/lens-studio-web-ailc/assistant/publish/{checkpoint_id}/status` | Polls status until snapcode is generated |

## 2. Authentication & Bot Attestation Analysis

Snapchat uses two-tier security:
1. **Interactive Login Layer (`accounts.snapchat.com`)**:
   - Uses gRPC-Web (`snapchat.janus.api.WebLoginService/WebLogin`).
   - Requires client device attestation generated by `kameleon.wasm` via `BootstrapAttestationSession`.
   - Headless cloud runners (like standard GitHub Actions or headless Docker containers) fail attestation, resulting in infinite submission spinners or captcha challenges.
2. **EasyLens Bearer SSO Layer**:
   - Once authenticated in the browser, Snapchat exchanges session credentials via `POST https://accounts.snapchat.com/accounts/sso` with `client_id=web-ar-applier`.
   - The resulting ticket is stored in `localStorage` under the key:
     `sc-sso-auth-ticket`
   - All subsequent AILC API calls use:
     `Authorization: Bearer <sc-sso-auth-ticket>`

## 3. GitHub Actions Setup

1. In your browser, open [easylens.snapchat.com](https://easylens.snapchat.com) while logged in.
2. Open DevTools (`F12`) -> **Application** -> **Local Storage** -> `https://easylens.snapchat.com`.
3. Copy the value of key `sc-sso-auth-ticket`.
4. Go to your GitHub repository -> **Settings** -> **Secrets and variables** -> **Actions**.
5. Add secret:
   - `SNAP_SSO_TOKEN`: (the token copied above)
   - `SNAP_COOKIE_HEADER`: (optional, cookies from DevTools Network tab)
6. Trigger the workflow under **Actions** -> **Snapchat EasyLens Pipeline** -> **Run workflow**.

## 4. Local Execution

```bash
export SNAP_SSO_TOKEN="<your_token>"
python3 pipeline_runner.py
```
